# DIGA Platform Foundation

This folder contains the initial project foundation for DIGA, an AI-powered Decision & Document Intelligence Platform for architecture projects.

## Current scope

- Next.js application scaffold
- TypeScript configuration
- Tailwind CSS setup
- App Router structure
- Supabase client foundation
- Documentation and environment template
