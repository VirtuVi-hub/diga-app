# PROJECT_CONTEXT

Welcome to the Delta project.

This directory contains the product, architecture, design, and implementation specifications required to work on the project.

Read only the documents required for your current task.

---

# Reading Order

## 1. Product

Read first:

- 01_PRODUCT.md
- 02_ARCHITECTURE.md

These define the product vision and system architecture.

---

## 2. Design

Read when implementing user-facing features:

- 06_DESIGN_PRINCIPLES.md

---

## 3. Workspace

Read only when implementing workspace-related functionality:

- ARCHITECTURE/Workspace.md
- WIREFRAMES/Workspace.md

These documents define the workspace architecture and interaction design.

---

## 4. Current Implementation

Read before beginning work:

- 03_CURRENT_STATE.md
- 04_ACTIVE_TASK.md

These describe the current implementation status and active work.

---

## 5. Product Decisions

Read when behaviour or UX decisions are relevant:

- 05_PRODUCT_DECISIONS.md

Do not invent product behaviour that contradicts these decisions.

---

## 6. Sprint

Finally, read the sprint you are implementing.

Example:

- SPRINTS/Sprint-3.6A-Unified-Workspace.md

The sprint defines the implementation scope.

---

# Working Principles

- Read only the documents required for the current task.
- Keep changes within the approved sprint scope.
- Do not modify unrelated functionality.
- Reuse existing components whenever possible.
- Preserve the product architecture and design principles.
- Validate all changes before completion.

---

# Completion Checklist

Before finishing:

- Update 03_CURRENT_STATE.md if implementation status changes.
- Update 04_ACTIVE_TASK.md if work is incomplete or handed over.
- Ensure lint, type checking, and build all pass.
- Summarize modified files and any known issues.

---
