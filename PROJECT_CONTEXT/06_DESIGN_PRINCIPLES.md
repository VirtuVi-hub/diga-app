# Delta Design Principles

This document defines the experience and visual philosophy of Delta.

It is more important than individual colors, spacing values, or typography scales.

When making UI decisions, prioritize these principles over convenience.

---

# The Feeling

Delta should feel like professional software built for architects.

The experience should communicate:

- Calm
- Precision
- Clarity
- Confidence
- Quality

Users should feel they are working inside a carefully designed architectural environment, not a generic business dashboard.

---

# Design Inspiration

Delta takes inspiration from products and experiences that value clarity, restraint, and craftsmanship.

Examples include:

- Apple
- Linear
- Arc Browser
- Figma
- Notion (editorial layouts)
- Architectural presentation boards
- Printed design portfolios

Do not imitate these products directly.

Instead, understand the qualities that make them feel refined.

---

# Editorial Before Dashboard

Delta should read like an architectural presentation rather than a spreadsheet.

Prefer:

- Clear hierarchy
- Generous whitespace
- Strong typography
- Calm layouts
- Focused information

Avoid:

- Dense dashboards
- Large metric cards
- Visual clutter
- Excessive icons
- Decorative graphics

---

# Knowledge First

The interface exists to help users understand project knowledge.

UI elements should support understanding.

They should never compete for attention.

If two elements compete visually, simplify one of them.

---

# Progressive Disclosure

Show only what users need.

Reveal complexity when required.

Avoid presenting every action at once.

Users should discover functionality naturally.

---

# Consistency

The same concept should always look and behave the same.

Examples:

Requirements always use the same visual language.

Meetings always use the same visual language.

Review Packages always use the same interaction patterns.

Consistency reduces cognitive load.

---

# Motion

Motion should communicate change.

It should never exist purely for decoration.

Animations should feel:

- Quick
- Smooth
- Subtle

Avoid dramatic transitions.

Avoid bouncing effects.

Avoid excessive animation.

---

# Color

Color communicates meaning.

Do not use color simply for decoration.

Accent colors should be used sparingly.

Whitespace should do most of the work.

---

# Typography

Typography is one of Delta's strongest design tools.

Use typography to establish hierarchy before introducing borders or backgrounds.

Good typography should reduce the need for additional visual elements.

---

# Components

Every component should answer one question clearly.

Avoid components that try to solve multiple unrelated problems.

Prefer focused, reusable components.

---

# Simplicity

Whenever faced with two solutions:

Choose the simpler one.

If the simpler solution weakens usability, choose the clearer one.

Never add complexity simply because it is technically possible.

---

# Long-Term Design Goal

Delta should become instantly recognizable through its design.

The goal is not to resemble existing SaaS products.

The goal is to establish a distinctive architectural design language that reflects the way architects think and work.
